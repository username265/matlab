## Digital Signal Processing with MATLAB


#### 1. fft spectrum analysis

   정현파와 합성 신호를 생성하고 FFT를 이용해 시간 영역의 파형과 주파수 스펙트럼을 분석했다.  
   스펙트럼을 정규화된 데시벨로 표현하여 신호에 포함된 주파수 성분을 확인했다.


#### 2. convolution modes

   간단한 펄스와 램프 신호에 MATLAB의 full과 same 컨볼루션을 적용했다.  
   출력 길이와 파형을 비교하여 두 방식이 결과 구간을 선택하는 차이를 확인했다.


#### 3. full convolution

   두 입력 신호의 원소를 곱하고 누적하는 중첩 반복문으로 전체 컨볼루션을 구현했다.  
   이를 통해 입력 신호의 중첩이 출력 파형을 형성하는 과정을 이해할 수 있다.


#### 4. same convolution

   전체 컨볼루션 결과에서 첫 번째 입력과 같은 길이의 중앙 구간을 추출하도록 구현했다.  
   두 번째 입력의 길이를 기준으로 시작 인덱스를 계산하여 출력 범위를 설정했다.


#### 5. convolution verification

   사각·삼각 펄스와 양·음의 구간을 갖는 신호에 직접 구현한 컨볼루션을 적용했다.  
   MATLAB 내장 함수의 결과와 출력 파형 및 절대 오차의 합을 비교하여 구현의 정확성을 검토했다.


#### 6. sampling and spectral analysis

   두 신호의 곱셈과 컨볼루션 결과를 시간 영역과 주파수 영역에서 분석했다.  
   샘플링 주파수를 변경하며 에일리어싱을 확인하고, 물리적 주파수와 정규화 주파수의 관계를 살펴봤다.


#### 7. I/Q envelope detection

   진폭 신호에 서로 직교하는 사인·코사인 반송파를 곱하여 두 신호를 구성했다.  
   두 신호의 제곱합에 제곱근을 취해 포락선을 추출하고, 원래 진폭 신호와 비교했다.


#### 8. ultrasound RF filtering

   초음파 RF 신호의 주파수 특성을 분석하고, 3~6 MHz의 경계 주파수를 갖는 50차 FIR 대역통과 필터를 설계했다.  
   각 센서 신호에 컨볼루션 기반 필터링을 적용하고, 처리 전후의 스펙트럼과 영상을 비교했다.

9. ultrasound image generation

   힐버트 변환으로 RF 신호의 포락선을 추출하고, 정규화와 로그 압축을 통해 초음파 영상을 생성했다.  
   원본·잡음·필터링 영상에 공통 정규화 기준을 적용하여 밝기와 세부 패턴의 변화를 확인했다.
